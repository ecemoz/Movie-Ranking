# 🎮 Movie Ranking by Ecem

This is a simple HTML project created to list Ecem's top 3 favorite shows of all time. The content includes short summaries of each show written in Turkish.

![image](https://github.com/user-attachments/assets/c7f32504-2f25-452a-940c-ad3dd1cb9759)


## 📄 File

* `Movie Ranking.html`: Main HTML file containing show rankings and descriptions.

## 📺 Shows Included

1. **Young Sheldon**
   A prequel to *The Big Bang Theory*, focusing on Sheldon Cooper’s childhood and early school life.

2. **The Big Bang Theory**
   A sitcom about four socially awkward scientists and their lives, spanning from 2007 to 2019.

3. **Gilmore Girls**
   A heartwarming drama-comedy about the bond between a mother and her daughter, originally aired from 2000 to 2007.

## 🌐 Technologies Used

* HTML5
* Basic CSS (optional styling can be added)

## 📝 Notes

* The content is written in Turkish.
* Designed to be lightweight and beginner-friendly.
* Can be viewed by simply opening the HTML file in any web browser.
